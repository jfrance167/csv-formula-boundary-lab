# Security scope

Synthetic CSV syntax learning only. Complete comparison and absent indicators do
not prove spreadsheet execution safety. Consumer/version/import/locale/edit-save-
reopen behavior remains unverified. Prefix demonstrations alter data; they are
not universal sanitizers. No hostile payloads, real credentials/customer data,
macros/DDE/command formulas/external links or automatic consumer launch.

For defects, use an available private channel to the repository owner with a
small inert reproduction and expected/observed report. No reporting endpoint is
configured in this local-only stage. Runtime uses standard library; scanner/Action
dependencies still require supply-chain review. Hosted alert inventory, protection
eligibility and dedicated secret-scanner checks remain unverified/unavailable.
